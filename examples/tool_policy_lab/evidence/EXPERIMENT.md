所有初始策略的 test/stress 成功率均为 0%。随机策略 test 成功率 3.90625%；规则执行器为 100%。

观察：过程惩罚版本在 dev 与最终 test 都提前提交；终局版本 3 种子均完成所有留出任务，但非法调用占比存在种子差异。因此不能只看成功率，也不能声称“智能超过规则执行器”。默认配置选终局奖励。

局限：结构化观测直接给出当前操作，策略主要学习路由/执行阶段；数据模板没有跨领域变化。过程惩罚的负面结果限于本奖励、初始化与预算。现有 test 结果已经被查看，后续调参应创建新的封存测试集，避免重复调参后的泛化误报。

故障指标同时按预先分配故障的任务和实际遭遇故障的任务计算。后者具有暴露偏差；完整分母见 report.json。

核验：checkpoint 重载后与内存策略指标一致；另外的契约测试验证 optimizer/RNG 恢复后的参数级一致性、真实 Task/Session 往返与随机微型 Qwen 的 LoRA 更新。

GPU 状态：Qwen2.5-0.5B-Instruct 的真实权重训练未运行。所有这里的成功率都是 CPU 小策略结果。
